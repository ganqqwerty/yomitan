# Yomitan Grammar Wildcards Demo

DEMO-1. Import the ZIP file from the report. Do not import this source folder one file at a time.

DEMO-2. Build and load the `codex/optional-grammar-wildcards` branch. Open **Settings → Advanced → Translation**. Enable **Japanese grammar wildcards**.

DEMO-3. Search from the first character of a Japanese example in a glossary. Yomitan should select the complete matching phrase.

DEMO-4. Only the full-width tilde `～` (U+FF5E) marks a gap. The wave dash `〜` and ASCII tilde `~` stay literal.

DEMO-5. This dictionary is a small feature demo. It is not a complete Japanese grammar reference.
